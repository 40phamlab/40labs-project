## C. Critical Findings & Discrepancies

### 1. Pricing Tier Conflict
*   **Finding:** The Competitive Report (§5.6) mentions Starter/Growth/Pro. The Business Mechanism (§3) mentions Class 1-4.
*   **Resolution:** Per the Business Mechanism, the **Class 1-4 model supersedes the earlier report**. The schema and types package are currently aligned with the correct "Class" model.

### 2. Theming & Design
*   **Finding:** Original design drafts suggested custom color/font sliders.
*   **Constraint:** The locked logic in `business.ts` and `settings.md` restricts this to a **Dark/Light toggle only**. The "Claymorphic" design language (solid surfaces, depth via shadows) is the confirmed direction.

### 3. Open Decision: Unsubscribe Data
*   **Status:** The decision between "Hard Delete" vs "Anonymize-and-Retain" (for the AI corpus) remains open.
*   **Current State:** The schema does not yet include an `is_anonymized` flag, meaning no accidental decision has been baked into the code yet.

### 4. Missing Gov/Enterprise Roles
*   **Finding:** Business Mechanism §2.5 mentions Gov/Enterprise read-only access.
*   **Gap:** The `app_user.role` enum only contains `sudo` and `staff`. We may need to add `observer` or `external_audit` roles to the schema if these users access the system directly.
